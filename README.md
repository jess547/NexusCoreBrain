# Overview

NEXUS Core Brain is a biological memory simulation engine designed for:

- Adaptive knowledge retrieval  
- Emotion‑aware reasoning  
- Narrative‑first cognition  
- Dynamic graph evolution  
- Multi‑agent orchestration  

It integrates with Google AI Studio, Gemini, Firestore, and Pinecone/Weaviate to create a persistent, evolving cognitive system.

---

# Core Features

- **Synaptic Weight Decay** — Nodes weaken over time using an Ebbinghaus‑inspired forgetting curve.  
- **Memory Reconsolidation** — Dormant nodes reactivate and return stronger when triggered.  
- **Emotion‑First Retrieval** — Emotion tags influence search, ranking, and graph traversal.  
- **Cue‑Walk Navigation** — A hippocampal‑inspired fuzzy retrieval algorithm.  
- **Scene‑First Rendering** — Every memory is reconstructed as a vivid narrative before showing data.  
- **Living Plasticity Loop** — Experiences strengthen edges and reshape the graph.  
- **Tron‑Inspired Visual Interface** — Neon nodes, glowing edges, glitch states, and real‑time cognition panels.

---

# Architecture

NEXUS is built across nine cognitive layers:

1. Knowledge Storage (Vault)  
2. Memory Dynamics (Synaptic Engine)  
3. Emotional Indexing (Feeling Layer)  
4. Cue‑Walk Navigation  
5. Scene‑First

   # Layer 1 — Knowledge Storage (The Vault)

### Node Structure
Each node contains:
- Title  
- Neural scene (narrative memory)  
- Structured facts  
- Metadata  
- 1536‑dim embedding  
- Access timestamps  
- Synaptic weight  

### Edge Structure
Edges represent:
- Semantic  
- Emotional  
- Temporal  
- Causal  
- Experience‑based relationships  

### Experience Backlinks
Automatically written whenever nodes are used.

---

# Layer 2 — Memory Dynamics (Synaptic Engine)

### Weight Decay
Exponential decay influenced by:
- Time since last access  
- Access frequency  
- Importance score  

### Reconsolidation
Dormant nodes reactivate when:
- Semantic similarity > 0.85  
- Emotional overlap  
- Temporal patterns  
- Causal chain detection  
- Explicit cues  

Reconsolidated memories return stronger than before.

---

# Layer 3 — Emotional Indexing (Feeling Layer)

Emotion is a primary retrieval axis.

Emotion taxonomy includes:
- urgency  
- curiosity  
- frustration  
- confidence  
- uncertainty  
- excitement  

Gemini extracts emotional state from text and context.

---

# Layer 4 — Cue-Walk Navigation

A hippocampal‑inspired retrieval algorithm:

1. Fuzzy semantic entry  
2. Emotional filtering  
3. Graph walk  
4. Resonance scoring  

Returns:
- Best path  
- Confidence  
- Alternative paths  

---

# Layer 5 — Scene-First Rendering

Every node generates a vivid, sensory, first‑person memory scene before showing structured data.

UI rendering order:
1. Scene  
2. Emotion tags  
3. Structured data  
4. Node metrics  
5. Graph connections  

---

# Layer 6 — Living Plasticity Loop

- Automatic experience logging  
- Edge strengthening  
- Weekly topology rebalance  
- Importance score recalculation  

Heavily‑used nodes become more central; unused nodes drift outward.
